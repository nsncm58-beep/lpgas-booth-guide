Admin reference. Everything below is read live from the deployed app, so it is always current.

Reading the deployed app…

Install the app

  1. Scan the QR (or open the link) on your phone.
  2. iPhone: Share button → Add to Home Screen. Android: browser menu → Install app.
  3. Open it from the home screen and create an account with your show's event code below.

Event codes

Each show's QR opens the app with that event code already filled in on the signup form (no typos). Codes marked "signup not open" work only for masters via the brand switcher until that show's exhibitor list is loaded.
